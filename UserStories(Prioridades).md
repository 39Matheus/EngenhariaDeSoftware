Este documento contém as Histórias de Usuário (User Stories) classificadas com prioridade **Alta** para o desenvolvimento do MVP do App de Gestão de Treinos.

---

## Módulo A: Gerenciamento de Usuários

### US00: Login
**História:**
Como usuário, eu quero poder me cadastrar e logar no aplicativo, para poder salvar minhas configurações e informações e conseguir acessá-las de outros dispositivos.

**Critérios de Aceite:**
* O usuário deve poder logar e deslogar, sendo possível utilizar o app mesmo sem estar logado (uso local).
* O usuário deve poder utilizar suas credenciais para logar em outros dispositivos e ter acesso ao perfil e configurações salvos em sua conta.

---

## Módulo B: Gestão de Treinos e Agendamento

### US01: Cadastro de Novo Treino
**História:**
Como usuário, eu quero criar um novo treino com um título personalizado (ex: "Treino A - Peito"), para organizar e segmentar minha rotina de academia.

**Critérios de Aceite:**
* O usuário deve conseguir acionar um botão para "Novo Treino" na tela principal.
* Deve haver um campo de texto obrigatório para o nome do treino.
* Os dados devem ser salvos no banco de dados local.

---

## Módulo C: Gestão de Exercícios

### US04: Inclusão de Exercícios
**História:**
Como usuário, eu quero adicionar múltiplos exercícios a um treino previamente criado, para montar minha ficha completa de atividades.

**Critérios de Aceite:**
* Dentro de um treino, deve haver um botão de "Adicionar Exercício".
* O usuário deve poder digitar o nome do exercício e salvá-lo na lista daquele treino.
