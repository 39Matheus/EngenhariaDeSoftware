## Windows
1. __Ambiente virtual__:
    ```bash
    python -m venv .venv
    ```
1. __Ative o ambiente__:
    ```bash
    ./.venv/Scripts/Activate.ps1
    ```
1. __Instale os componentes__:
    ```bash
    pip install -r requirements.txt
    ```
1. __Rode a API__:
    ```bash
    python manage.py runserver
    ```

## Linux (Ubuntu e derivados)
1. __Ambiente virtual__:
    ```bash
    python3 -m venv .venv
    ```
1. __Ative o ambiente__:
    ```
    ./.venv/bin/activate
    ```
1. __Instale os componentes__:
    ```bash
    pip3 install -r requirements.txt
    ```
1. __Rode a API__:
    ```bash
    python3 manage.py runserver
    ```
